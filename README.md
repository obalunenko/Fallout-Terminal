# Fallout-Terminal

Electron-приложение для ведущего настольных RPG: транслирует Fallout-style терминал (взлом паролей, навигация по файлам) игрокам по локальной сети через браузер, пока мастер управляет содержимым в отдельном окне.

## Структура

- `main.js` — Electron main-процесс (окно мастера, сессии, IPC)
- `server/` — Express + WebSocket сервер, раздающий клиентскую страницу и синхронизирующий состояние
- `master/` — интерфейс мастера (Electron-окно)
- `client/` — страница, которую видят игроки в браузере
- `sessions/` — сохранённые сессии (`.json`)

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm start
```

Откроется окно мастера; игроки подключаются со своих устройств по адресу, который приложение покажет в интерфейсе (`http://<IP-мастера>:3690`).

## Сборка

```bash
npm run build           # установщик NSIS (Windows x64)
npm run build:portable  # portable .exe
npm run build:dir       # неупакованная сборка в dist/win-unpacked (для отладки)
```

Собранные файлы попадают в `dist/` (в репозиторий не коммитятся, см. `.gitignore`).
