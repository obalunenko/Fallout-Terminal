# Fallout-Terminal

Electron-приложение для ведущего настольных RPG: транслирует Fallout-style терминал (взлом паролей, навигация по файлам) игрокам по локальной сети через браузер, пока мастер управляет содержимым в отдельном окне.

## Структура

- `main.js` — Electron main-процесс (окно мастера, сессии, IPC)
- `server/` — Express + WebSocket сервер, раздающий клиентскую страницу и синхронизирующий состояние
- `master/` — интерфейс мастера (Electron-окно)
- `client/` — страница, которую видят игроки в браузере
- `sessions/` — сохранённые сессии (`.json`)

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm start
```

Откроется окно мастера; игроки подключаются со своих устройств по адресу, который приложение покажет в интерфейсе (`http://<IP-мастера>:3690`).

## Публичная ссылка через ngrok

Установите [бинарник ngrok](https://ngrok.com/download), один раз добавьте токен аккаунта и запустите приложение в режиме туннеля, задав логин и пароль для игроков:

```bash
ngrok config add-authtoken <ВАШ_ТОКЕН>
NGROK_USERNAME=players NGROK_PASSWORD='<ПАРОЛЬ_НЕ_КОРОЧЕ_8_СИМВОЛОВ>' npm run start:ngrok
```

В поле «АДРЕС ДЛЯ ИГРОКОВ» автоматически появится постоянная публичная ссылка `https://fallout-terminal.ngrok.app`. Её можно открыть кликом и отправить игрокам; при открытии браузер запросит заданные логин и пароль. Без правильных данных ngrok вернёт `401 Unauthorized`, включая попытки установить WebSocket-соединение. Туннель закрывается вместе с приложением.

Публичный режим намеренно не запускается без `NGROK_USERNAME` и `NGROK_PASSWORD`, чтобы ссылка случайно не оказалась открытой. Пароль должен содержать от 8 до 128 символов. Кредентиалы передаются во временную ngrok Traffic Policy, удаляемую сразу после запуска туннеля, и не сохраняются в проекте.

Также поддерживается одна переменная в формате `логин:пароль`:

```bash
NGROK_BASIC_AUTH='players:<ПАРОЛЬ_НЕ_КОРОЧЕ_8_СИМВОЛОВ>' npm run start:ngrok
```

При необходимости домен можно переопределить:

```bash
NGROK_DOMAIN=другой-домен.ngrok.app npm run start:ngrok
```

Если `ngrok` не находится через `PATH`, укажите полный путь к бинарнику:

```bash
NGROK_BIN=/полный/путь/ngrok npm run start:ngrok
```

Для собранного приложения режим также можно включить аргументом `--ngrok`.

## Сборка

```bash
npm run build           # установщик NSIS (Windows x64)
npm run build:portable  # portable .exe
npm run build:dir       # неупакованная сборка в dist/win-unpacked (для отладки)
```

Собранные файлы попадают в `dist/` (в репозиторий не коммитятся, см. `.gitignore`).
