Положите сюда свои звуковые файлы (.mp3 / .wav / .ogg / .m4a / .webm).
Названия файлов внутри папки могут быть любыми — приложение просто берёт
всё, что лежит в нужной папке.

ambient/      — фоновый гул терминала, зациклен (например obj_computerzax_hum_lp.*)
hack-good/    — звук успешного взлома (например ui_hacking_passgood.*)
hack-bad/     — звук неверной попытки при взломе (например ui_hacking_passbad.*)
menu-focus/   — звук наведения на пункт обычного меню (например ui_menu_focus.*)
single/       — случайный звук при наведении на символ во время взлома
multiple/     — случайный звук при наведении на слово во время взлома
enter/        — случайный звук при клике на слово/символ во время взлома
charscroll/   — случайный звук при появлении каждой новой строки текста
              (например ui_hacking_charscroll.*)

Если папка пустая — соответствующий звук просто не проигрывается,
ошибок из-за этого не будет.
