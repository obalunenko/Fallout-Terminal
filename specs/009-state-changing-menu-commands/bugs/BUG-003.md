# Bug Report: Общий сброс по-прежнему не снимает выполненное состояние

**Type**: Implementation drift
**Severity**: High
**Feature**: `009-state-changing-menu-commands`
**Reported**: 2026-08-17
**Status**: Patched
**Patched**: 2026-08-17
**Regression of**: BUG-002

## Description

BUG-002 всё ещё воспроизводится в фактическом приложении мастера. После нажатия кнопки «Сбросить все состояния» наблюдаемого изменения не происходит: в приложении мастера команда остаётся помеченной как выполненная, и подключённые игроки также продолжают видеть её выполненной.

**Expected**: после подтверждения общего сброса все и только выполненные команды выбранного терминала одним атомарно сохранённым изменением переходят из `COMPLETED` в `INITIAL`. Мастер и все активные player-представления без перезагрузки показывают исходное состояние, а оно сохраняется после повторного открытия той же writable-сессии.

**Actual**: действие не меняет видимое состояние ни у мастера, ни у игроков; команда остаётся выполненной во всех наблюдаемых представлениях.

Повторное ручное воспроизведение опровергает статус `Patched` и заявленную verification для BUG-002. На этапе отчёта не установлено, достигает ли вызов канонической backend-мутации и меняется ли document revision; это должно быть зафиксировано следующим падающим воспроизведением на том же native-сценарии.

## Root Cause Analysis

Точный технический слой отказа пока не локализован и не должен считаться тем же, что ранее описанный stale `Nav.CommandNodeID`: пользователь наблюдает completed-состояние одновременно в приложении мастера и у игроков, поэтому возможен более ранний разрыв — от обработчика кнопки и Wails-вызова до backend no-op/error либо непринятой канонической revision.

Установленная процессная причина — существующая verification BUG-002 не воспроизводит фактический native-путь достаточно точно либо не проверяет его обязательные наблюдаемые результаты. Тесты T056–T058 и итоговая T040 дали ложноположительное подтверждение исправления, поскольку при их успешном результате реальный сценарий всё ещё нарушает FR-023, SC-009 и SC-016.
