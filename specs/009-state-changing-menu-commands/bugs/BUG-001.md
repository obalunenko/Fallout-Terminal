# Bug Report: Кнопки сброса не сбрасывают состояния команд

**Type**: Implementation drift
**Severity**: High
**Feature**: `009-state-changing-menu-commands`
**Reported**: 2026-08-17
**Status**: Patched
**Patched**: 2026-08-17

## Description

В мастерском интерфейсе кнопки «Сбросить состояние» и «Сбросить все состояния» не выполняют заявленный переход: после нажатия выполненное состояние выбранной команды либо всех команд текущего терминала не сбрасывается. Команды остаются в выполненном состоянии вместо возврата в исходное.

Ожидаемое поведение: после подтверждения индивидуального сброса исходное состояние восстанавливается только у выбранной команды; после подтверждения общего сброса исходное состояние восстанавливается у всех и только команд выбранного терминала. Изменение должно быть атомарно сохранено и синхронизировано с активными представлениями.

## Root Cause Analysis

Причиной дефекта оказалась встроенная демонстрационная сессия: она содержала заранее заполненные `commandStates` с завершёнными состояниями, но сама bundled demo намеренно доступна только для чтения.

Интерфейс корректно показывал кнопки сброса для этих состояний, однако backend запрещал сохранение изменений в неизменяемый demo-файл. Поэтому подтверждённый индивидуальный или общий сброс не мог стать долговечным и после обновления проекции команды оставались завершёнными.

Производственный reset-путь для пользовательских writable-сессий — `master UI → desktop API/Wails binding → private handler → session mutation → session-state/runtime refresh` — оказался исправен.

## Resolution

1. Удалены заранее завершённые `commandStates` из встроенной read-only demo-сессии.
2. State-changing команды сохранены в demo в исходном состоянии.
3. Документирован сценарий создания writable-копии сессии для выполнения и сброса команд.
4. Добавлены регрессионные проверки индивидуального и общего сброса, отмены подтверждения, document revision, active runtime projection и повторного открытия того же session JSON.

- Отмена подтверждения не изменяет документ или revision.
